# Brand Constitution: Reference Architecture

## 1. Corporate Foundation (Parent Constitution)

### Core Mission & Register
- **Primary Voice**: Authoritative, technically precise, empirical.
- **Tone Vectors**:
  - `Confidence`: 0.85
  - `Empiricism`: 0.90
  - `Formality`: 0.70
  - `Hype / Exaggeration`: 0.00 (Strictly Zero)

### Banned Terminology & Clichés
The following words and phrases are strictly forbidden across all published assets:
- `delve`
- `tapestry`
- `game-changer`
- `in today's fast-paced world`
- `testament to`
- `revolutionary`
- `cutting-edge`

### Mandatory Assertions
1. Every statistical metric must be accompanied by an explicit source, test condition, or attribution.
2. All technical comparisons must evaluate trade-offs; one-sided praise is rejected.
3. Typography must use standard ASCII straight quotes (`"..."`, `'...'`).

---

## 2. Subsidiary Override Rules (Constitutional Inheritance)

### Sub-Brand A: Enterprise Cloud (Endorsed)
- **Inherits**: All Corporate Foundation rules.
- **Tone Overrides**:
  - `Formality`: 0.85 (Increased for enterprise procurement audience)
- **Allow-list Additions**: High-availability, SLO, SLA, multi-tenant.

### Sub-Brand B: Developer Tools (House of Brands)
- **Inherits**: Ethical and legal compliance rules only.
- **Tone Overrides**:
  - `Formality`: 0.40 (Conversational engineering register)
  - `Contractions`: Allowed (`it's`, `don't`, `you'll`)
- **Format**: Code-first examples with command-line snippets.
